# 이전 버전과 원래 작업 기록

현재 실행 소스는 저장소 루트의 `bmo/`, `tests/`, `tools/`와 실행기다. 최신 동작 설명은 루트 README와 개인 개발 문서를 기준으로 한다.

## 남긴 자료

- [개인 프로젝트 Word 보고서](../BMO_개인프로젝트보고서.docx)
- [기존 수행평가 보고서 공개용 사본](archive/school-project-report.docx) — 제공된 ver3 문서의 내용·그림 배치를 유지하고 사진만 축소 압축한 사본이다. 로컬 원본은 보존했다.
- [이전 README](archive/README-legacy.md) — 개발 중 계속 추가된 작업 기록이다. 과거 기본값과 현재 다른 설명도 있으므로 실행 안내로 우선 사용하지 않는다. 일부 옛 상대 링크는 당시 폴더 기준이다.
- 루트 `BMO-*.md`, `PI-SETUP.md`, `VALIDATION.md` — 당시 설계, 인수인계, 설치와 검증 기록. 같은 날짜 안에서도 준비·배포·수정 단계가 다를 수 있다.
- [`versions/manifest.json`](../versions/manifest.json) 및 이전 버전 ZIP 10개 — 자동 대화 실험부터 최신 새 사진 처리까지의 보관본이다. 개별 버전의 미완성·롤백 상태를 유지했다.

## 공개용으로 바꾼 부분

실제 API 키 파일, 인증서·개인 키, 가상 환경, 원시 대화·카메라 시험 자료, 다른 프로젝트와 임시 QA 출력은 포함하지 않았다. 접속 예시에는 실제 파이 사용자명과 주소 대신 `pi-user`, `192.168.1.50`을 쓴다. 자신의 환경에 맞게 바꿔야 한다.

이전 ZIP도 같은 접속 식별자만 예시로 바꾼 공개 사본이다. 이 때문에 ZIP 해시는 로컬 보관본과 다르다. 목록의 `source_sha256`은 로컬 원본, `sha256`은 공개 사본을 가리킨다. 기존 키 템플릿은 빈 값이며 현재 소스에는 `private_config.example.py`만 제공한다.

이 저장소는 2026년 10월 22일까지의 소스와 기록을 모은 첫 공개 스냅샷이다. Git 커밋 날짜를 과거 개발 날짜로 꾸미지 않았으며 실제 과정은 개발일지와 보관 버전에 기록했다. 시연영상은 아직 제작 자료로 추가되지 않았다.
